SLIDE 01 — PORTADA

Bienvenido al Roadmap de Data Engineering de Z2H Academy.

Una ruta diseñada para pasar de trabajar con datos a construir sistemas de datos, avanzando desde SQL hasta Lakehouse y AI.

SLIDE 02 — EL PROBLEMA

Aprender Data Engineering no debería significar memorizar una lista de herramientas.

El verdadero reto es entender cómo funcionan los sistemas de datos y aprender a tomar decisiones de ingeniería.

SLIDE 03 — EL MERCADO

El mercado actual sigue demandando fuertemente SQL y Python, junto con ETL, modelado, cloud, orquestación y procesamiento distribuido.

Por eso nuestra ruta parte de los fundamentos y crece progresivamente.

SLIDE 04 — LA EVOLUCIÓN

Data Engineering evolucionó mucho más allá del ETL tradicional.

Hoy hablamos de Analytics Engineering, Cloud, Streaming, Lakehouse, Governance y, cada vez más, de AI aplicada a los sistemas de datos.

SLIDE 05 — LA TESIS

En Z2H no empezamos por las herramientas.

Primero entendemos el problema, después construimos el sistema y finalmente elegimos la tecnología que necesitamos para resolverlo.

SLIDE 06 — LA PROGRESIÓN

El Roadmap está organizado en ocho niveles.

Comenzamos con SQL y avanzamos por Batch, Paralelismo, OLAP, Modelado, Streaming, Lakehouse y finalmente AI aplicada a Data Engineering.

SLIDE 07 — EL MERCADO PROFESIONAL

La carrera también evoluciona con esa progresión.

Puedes comenzar construyendo pipelines y terminar diseñando plataformas de datos distribuidas, sistemas de streaming y arquitecturas modernas de Lakehouse.

SLIDE 08 — COMPENSACIÓN

Data Engineering también es un mercado global.

Existen oportunidades en Latinoamérica y también posiciones internacionales, con diferencias importantes de compensación según experiencia, especialización, empresa y ubicación.

SLIDE 09 — EL PORTFOLIO

Durante el Roadmap no solo estudias.

Construyes cinco proyectos que evolucionan contigo y permiten demostrar cómo aplicas ingeniería sobre datos reales.

SLIDE 10 — EL PRIMER PROYECTO

Comenzamos con SQL y un Data Warehouse.

Construyes el modelo, cargas millones de registros, validas los datos y finalmente migras el sistema a Snowflake.

SLIDE 11 — DE BATCH A LAKEHOUSE

A medida que crecen los datos, también crece el sistema.

Pasamos de Python y pandas a Polars, DuckDB, dbt, Kafka y finalmente Spark y Lakehouse.

SLIDE 12 — UN ENTORNO. TODO EL ROADMAP.

Todo esto ocurre sobre un entorno reproducible.

Trabajamos con Docker y GitHub Codespaces, incorporando nuevos componentes a medida que avanzas por cada nivel.

SLIDE 13 — EL RESULTADO

Al finalizar no tendrás solamente una colección de tecnologías.

Tendrás la experiencia de construir sistemas de datos completos, desde SQL hasta Lakehouse y AI.

Esto es Data Engineering en Z2H Academy.
